# Chess Game

A professional chess game that runs fully in the browser — no login, no server, just open and play.

## Two ways to play

- **Vs Computer** — play as White, Black or Random, with Easy / Medium / Hard difficulty
- **Two Players** — both sides on the same device

## Features

- Full real chess rules: castling, en passant, pawn promotion, check, checkmate and stalemate
- Draws by threefold repetition, fifty-move rule and insufficient material
- Tap-to-move or drag pieces, with legal-move hints
- Live evaluation bar, captured pieces and material score
- Full move list in standard notation (e4, Nf3, O-O…)
- Game clocks: Bullet, Blitz and Rapid, with increments
- Undo, flip board, draw offers, resign and move sounds

## How to run

Open `index.html` in any browser. Everything (including the chess engine) runs on the page itself.
